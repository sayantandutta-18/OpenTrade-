## [Unreleased]

### Added
- Phase 1 Core Order Book & Simulation Engine (`T1.1`–`T1.12`):
  - `opentrade/engine/book.py`: FIFO deque price levels, sorted bid/ask sides, integer-tick prices, O(1) lookup/cancel, queue position, depth snapshots, and canonical `event_log_sha256` (`AC-11`, `AC-16`, `FR-11`, `FR-12`).
  - `opentrade/engine/matching.py`: Price-time priority matching for LIMIT, MARKET, IOC, FOK, POST_ONLY, cancel, modify (preserving FIFO on size decrease), strict input validation, and self-trade prevention (`CANCEL_NEWEST` / `CANCEL_OLDEST`) (`AC-12`–`AC-15`, `FR-13`, `FR-14`, `FR-19`).
  - `opentrade/engine/invariants.py`: Automated invariant checker verifying no crossed book (`AC-17`), sorted sides (`AC-11`), FIFO ordering, and volume conservation across 1,000-operation Hypothesis property tests.
  - `opentrade/engine/profiles.py` & `opentrade/engine/order_flow.py`: Preset liquidity profiles (`synthetic_default`, `thin_book`, `deep_book`, `high_volatility`) with `SYNTHETIC`/`CALIBRATED` provenance and deterministic `random.Random(seed)` Poisson/Hawkes order-flow generator (`FR-15`–`FR-17`, `FR-21`, `FR-37`, `FR-52`).
  - `opentrade/engine/impact.py`, `opentrade/engine/metrics.py`, `opentrade/engine/runner.py`: Parent-order slicing across TWAP, VWAP, POV, and IS (Almgren-Chriss), implementation shortfall & temporary/permanent impact attribution, and deterministic multi-size/multi-strategy sweep runner (`FR-22`, `FR-25`, `FR-27`, `FR-52`).
  - `opentrade/services/runs.py`: `save_run`, `list_runs` (paginated), `get_run`, and `delete_run` with strict per-user 404 ownership isolation (`AC-7`, `AC-21`).
  - Phase 1 integration & TRD §4 performance benchmark suite in `tests/engine/test_benchmarks.py` (< 10 ms single order injection, < 30 s 20-size sweep).
- Streamlit authentication pages (`opentrade/ui/pages/auth_pages.py`) for Register (with upfront AC-10 privacy note and password rules, anti-enumeration confirmation, and resend link), Log in (with lockout/rate-limit feedback and unverified-user banner), Verify email (token confirmation and resend flow), Forgot password (uniform anti-enumeration reply), and Reset password (password rules, expired-token prompt, and session clear), wired into `opentrade/ui/app.py` and `opentrade/ui/state.py` with headless `AppTest` coverage in `tests/ui/test_auth_pages.py` per AC-10, AC-42, FR-1–FR-7, FR-53, US-1–US-5, and USER_FLOW.md Flows 2–4, completing Phase 0 (T0.17).
